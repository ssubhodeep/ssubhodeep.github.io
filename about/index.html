03 Who I am

Precision, at scale.

I'm a high-impact Android engineer who builds systems that demand precision — real-time BLE pipelines connecting ELD hardware to mobile apps, and FMCSA-compliant applications used daily by trucking fleets across the US.

My engineering philosophy centers on clean architecture, measurable performance, and long-term maintainability. I own the full lifecycle — system design, API collaboration, Play Store deployment, and production monitoring.

I actively integrate AI-driven development practices into my workflow, using tools like GitHub Copilot for zero-code UI scaffolding and handling multiple feature workstreams in parallel — shipping faster without compromising quality.

Beyond code, I enjoy mentoring developers, introducing structured Agile practices, and translating complex requirements into practical, scalable solutions.
